README

1\. Project Overview

1.1 Real-world Problem

In the current online book market, readers face several challenges:



Scattered Information: Book details and reviews are spread across multiple platforms, requiring users to switch between websites.



Variable Review Quality: User reviews often lack credibility and structure, making it hard to make informed decisions.



1.2 Project Goal

Our goal is to build an integrated online platform where users can browse, purchase, and review books in one place.


2\. Key Features

Book Browsing \& Categorisation: Browse books by category, author, or publisher.



Advanced Search \& Filters: Search by keywords, filter by rating, price, or publication date.



Review \& Rating System: Post reviews, rate books, and upvote helpful comments.


Purchase \& Payment: Buy physical or e-books with secure payment options.



User Account Management: Register, log in, and manage personal bookshelf.



Data Security: Ensure secure authentication and encrypted data storage.



3\. Technology Stack

Frontend: Vue



Backend: Spring Boot (RESTful APIs)



Database: MySQL (JPA/Hibernate for ORM)



Version Control: GitHub with Git Flow



Project Management: JIRA (Scrum methodology)
